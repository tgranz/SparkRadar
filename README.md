# SparkRadar
**For real this time:** this is the *third* rewrite of the SparkRadar codebase from the ground up.

SparkRadar is a free, reliable, completely frontend web application so you can track the weather like a pro for free. It includes advanced features such as instant alerts (from the NWWS-OI, recieves alerts as fast as your news anchor), dual-pane radar, professional radar products, and so much more.

### https://sparkradar.app

## Test
1) Run `npm install`.
2) Run `npx run dev`. Code will hot-reload without browser refreshing thanks to Vite.
